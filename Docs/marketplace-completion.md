# Essential marketplace release

1. Replace public local catalogue reads with published Supabase records. Research 15 real places from official sources, with dated evidence. Distinguish source review from host confirmation; do not invent prices, availability, reviews or photo licences.
2. Put discovery first: compact trip search, camping styles, recommendations, states and destinations. Merge resources in navigation, support global search, and preserve filters in URLs.
3. Require email-code authentication for enquiries, retain trip drafts, validate and persist requests on the server, then prepare a recipient-controlled WhatsApp message or offer the official operator/support route.
4. Persist forms before confirmations. Send complete persisted fields through a retryable email outbox. Implement account contact details, saved campsites and enquiry history.
5. Verify server types, API permissions, validation, published-only routes, forms and deployment. Push and deploy the verified changes.

Community invite is intentionally unset at the user's request. Never substitute a dummy link. Official photographs must be traceable to the specific property; source attribution is not a claim of an image licence or host partnership.
